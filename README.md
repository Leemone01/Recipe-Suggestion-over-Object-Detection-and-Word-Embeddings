# Recipe Suggestion over Object Detection and Word Embeddings
## Introduction
This project introduces an Intelligent System designed to detect ingredients inside a refrigerator and recommend recipes that can be prepared with the available stock. 
In case of missing ingredients, the system proposes suitable alternatives based on the available items. 

## Repository details
The repository is organized as follows:
- `Ingredient_Detection`: Contains the notebook and all the files necessary to perform ingredient detection.
- `Ingredient_Substitution`: Contains the notebook and all the files necessary to perform ingredient substitution.
- `main.ipynb`: The notebook used to test the final application.
- `demo_data`: Contains the sample files used for testing the final application.

## How to run
Before testing the project, download the RecipeNLG dataset from the following link: https://recipenlg.cs.put.poznan.pl/.
Place then `full_dataset.csv` file into the `Ingredient_Substitution\datasets` directory, renaming the file to `recipes_for_embeddings.csv`.

Due to GitHub file size limitations, the following files are missing:
-   `Ingredient_Detection\training\res\model_x`:  training results for YOLO model x;
-   `Ingredient_Substitution\datasets\refined_recipes_for_embeddings.csv`: refined recipes dataset used to train the Word2Vec model;
-   `Ingredient_Substitution\GloVe\refined_recipes_for_embeddings.txt`: refined recipes dataset used to train the GloVe model.

All these files can be generated by running the appropriate cells first: keep this in mind before executing a cell that requires one of these files.


The project was tested on Google Colab, and each notebook contains all the necessary steps to run it directly on Colab.
To run the project locally, first ensure you have Python 3.12.13 installed (the version used by Google Colab).  
Next, navigate to the project directory and install all the required dependencies by running the following command:
    
    pip install -r requirements.txt


To compile and train GloVe, the prerequisites are taken directly from the project's official GitHub repository (https://github.com/stanfordnlp/GloVe):

    Make sure you have the following prerequisites [...]:
        -   GNU Make
        -   GCC (Clang pretending to be GCC is fine)
        -   Python and NumPy
